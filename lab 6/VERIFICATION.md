# Результаты проверки

Проверено 14 октября 2026 года в рабочей среде Windows, Python 3.12.7 (MSYS2).

- Зависимости установлены в `.venv`: Flask 3.1.3, Flask-SQLAlchemy 3.1.1, SQLAlchemy 2.1.4.
- `python -m unittest discover -s tests -v`: **9 тестов, OK**. Внутри тестов выполняются дополнительные варианты через subTest.
- Проверены email/sms/push, сохранение и порядок истории, сохранность после повторного создания приложения с тем же файлом базы.
- Проверены отсутствующие поля, пустые строки, неверные типы значений, неизвестный канал, JSON-массив/скаляр/null, повреждённый JSON и неверный Content-Type.
- Проверены идентичность Singleton, повторный init_app, выбор конкретных сервисов и демонстрационный результат.
- Искусственно вызвана ошибка commit: подтверждены код 500, вызов rollback, отсутствие неудачной записи и успешная следующая отправка.
- Проверена отдача русскоязычного HTML с кодом 200.
- `tests/http_smoke.py`: поднят настоящий HTTP-сервер на свободном локальном порту; GET страницы — 200, POST для всех трёх каналов — 201, GET истории — три записи. Сервер остановлен после проверки.
- Python-файлы прошли compileall; встроенный JavaScript разобран Node.js без синтаксических ошибок.
- `pip check`: No broken requirements found.

Все тестовые записи находились во временных базах, которые удалены после проверки. Пользовательская база `instance/notifications.db` создастся при первом обычном запуске.

Проверка кликов и отображения страницы в настоящем браузере **не выполнялась**. Проверены HTML, синтаксис JavaScript и HTTP/API; визуальный результат и взаимодействие в браузере нужно проверить вручную.
